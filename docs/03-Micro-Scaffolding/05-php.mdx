# PHP-Grundlagen
Lernende bearbeiten Logik- und Syntaxaufgaben in PHP, um die serverseitige Logik für die Organisation einer Radtour zu entwickeln. Du begleitest den Lernprozess und unterstützt mit Micro-Scaffolding bei typischen PHP-Stolperfallen.

## Aufgabe: Hilfsfragen formulieren
Finde passende unterstützende Fragen nach den Regeln des Micro-Scaffolding für die folgenden Situationen beim Erlernen von PHP.
Gehe dabei wie folgt vor:

1. Analysiere den Fehler im Code. Falls nötig, betrachte die Lösung.
2. Formuliere eine **minimale** Hilfsfrage. Schreibe sie auf die <span style={{color: '#86aea6', fontWeight: 'bold'}}>grüne Karte</span>.
3. Formuliere eine **stärkere** Hilfsfrage. Schreibe sie auf die <span style={{color: '#e9c169', fontWeight: 'bold'}}>orangefarbene Karte</span>.

### Beispiel-Situation

```php
<?php
$radfahrer = 10;
echo $Radfahrer;
```

```php
  echo "Temperatur ist genau am Gefrierpunkt";

```

<summary>Der korrigierte Code</summary>

### Situation 4: Alle übrigen Räder verleihen

```php
<?php
$uebrigeRaeder = 4;

while ($uebrigeRaeder > 0) {
  echo "Ein Rad wurde erfolgreich verliehen.";
}
```

<details>
<summary>Der korrigierte Code</summary>

```php {6}
<?php
$uebrigeRaeder = 4;

while ($uebrigeRaeder > 0) {
  echo "Ein Rad wurde erfolgreich verliehen.";
  $uebrigeRaeder--; 
}
```

<div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginTop: '1rem' }}> <span>Schleifenvariable nicht verändert (-> Endlosschleife).</span> <a href="https://www.w3schools.com/php/php_loop_while.asp" target="_blank" style={{ backgroundColor: '#32965D', color: 'white', padding: '5px 12px', borderRadius: '6px', textDecoration: 'none', fontWeight: 'bold', fontSize: '0.85rem', whiteSpace: 'nowrap' }}> Mehr Hilfe im Web </a> </div>

### Situation 6: Kosten-Kalkulation
Elif wundert sich, dass ihr Programm den Gesamtpreis nicht ausgibt. Formuliere sinnvolle Hilfsfragen.

```php
<?php
function berechneGesamtpreis($radmiete, $verpflegung) {
  $radmiete + $verpflegung;
}

echo berechneGesamtpreis(40, 20);
```

<details>
<summary>Der korrigierte Code</summary>

```php {3}
<?php
function berechneGesamtpreis($radmiete, $verpflegung) {
  return $radmiete + $verpflegung;
}

echo berechneGesamtpreis(40, 20);
```

<div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginTop: '1rem' }}> <span>Rückgabe (```return```-Anweisung) fehlt.</span> <a href="https://www.w3schools.com/php/php_functions.asp" target="_blank" style={{ backgroundColor: '#32965D', color: 'white', padding: '5px 12px', borderRadius: '6px', textDecoration: 'none', fontWeight: 'bold', fontSize: '0.85rem', whiteSpace: 'nowrap' }}> Mehr Hilfe im Web </a> </div>
