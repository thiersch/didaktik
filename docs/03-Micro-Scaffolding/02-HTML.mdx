# HTML-Grundlagen
Lernende beschäftigen sich mit HTML als Grundlage der Webentwicklung. Sie zeichnen Inhalte einer Website zur Organisation einer Radtour aus. Du begleitest den Lernprozess und unterstützt mit Micro-Scaffolding.

## Aufgabe: Hilfsfragen formulieren
Finde passende unterstützende Fragen nach den Regeln des Micro-Scaffolding für die folgenden Situationen beim Erlernen von Webentwicklung.
Gehe dabei wie folgt vor:

1. Analysiere den Fehler im Code. Falls nötig, betrachte die Lösung.
2. Formuliere eine **minimale** Hilfsfrage. Schreibe sie auf die <span style={{color: '#86aea6', fontWeight: 'bold'}}>grüne Karte</span>.
3. Formuliere eine **stärkere** Hilfsfrage. Schreibe sie auf die <span style={{color: '#e9c169', fontWeight: 'bold'}}>orangefarbene Karte</span>.

### Situation 8: Anmeldeformular

```html
   <!-- innerhalb von Formular -->
   <label>Vorname:</label>
   <input name="firstname">
   <button type="submit">Absenden</button>
</form>
```

<details>
   <summary>Der korrigierte Code</summary>

```html {2-3}
   <!-- innerhalb von Formular -->
   <label for="fname">Vorname:</label>
   <input id="fname" name="firstname">
   <button type="submit">Absenden</button>
</form>
```

<div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginTop: '1rem' }}> <span>Zuordnung ```for```/```id``` fehlt.</span> <a href="https://www.w3schools.com/tags/tag_label.asp" target="_blank" style={{ backgroundColor: '#32965D', color: 'white', padding: '5px 12px', borderRadius: '6px', textDecoration: 'none', fontWeight: 'bold', fontSize: '0.85rem', whiteSpace: 'nowrap' }}> Mehr Hilfe im Web </a> </div>
