# SQL-Grundlagen
Lernende nutzen SQL, um die organisatorischen Daten einer Radtour zu verwalten. Du begleitest den Lernprozess und unterstützt mit Micro-Scaffolding bei Abfragen und Datenbank-Strukturen.

## Aufgabe: Hilfsfragen formulieren
Finde passende unterstützende Fragen nach den Regeln des Micro-Scaffolding für die folgenden Situationen beim Erlernen von SQL.
Gehe dabei wie folgt vor:

1. Analysiere den Fehler im Code. Falls nötig, betrachte die Lösung.
2. Formuliere eine **minimale** Hilfsfrage. Schreibe sie auf die <span style={{color: '#86aea6', fontWeight: 'bold'}}>grüne Karte</span>.
3. Formuliere eine **stärkere** Hilfsfrage. Schreibe sie auf die <span style={{color: '#e9c169', fontWeight: 'bold'}}>orangefarbene Karte</span>.

### Situation 7: Touren filtern
Tim möchte Touren für Heidenheim und Ulm zeigen. Er wundert sich, warum die Ergebnisliste leer bleibt.

```sql
SELECT * FROM touren
WHERE startort = 'Heidenheim' AND startort = 'Ulm';
```

<details>
<summary>Der korrigierte Code</summary>

```sql {2}
SELECT * FROM touren
WHERE startort = 'Heidenheim' OR startort = 'Ulm';
```
