# CSS-Grundlagen
Lernende gestalten eine Webseite für die Organisation einer Radtour mit CSS. Du begleitest den Lernprozess und unterstützt mit Micro-Scaffolding bei typischen Styling-Fehlern.

## Aufgabe: Hilfsfragen formulieren
Finde passende unterstützende Fragen nach den Regeln des Micro-Scaffolding für die folgenden Situationen beim Erlernen von CSS.
Gehe dabei wie folgt vor:

1. Analysiere den Fehler im Code. Falls nötig, betrachte die Lösung.
2. Formuliere eine **minimale** Hilfsfrage. Schreibe sie auf die <span style={{color: '#86aea6', fontWeight: 'bold'}}>grüne Karte</span>.
3. Formuliere eine **stärkere** Hilfsfrage. Schreibe sie auf die <span style={{color: '#e9c169', fontWeight: 'bold'}}>orangefarbene Karte</span>.

### Beispiel-Situation

```css
p {
  color: red
  font-size: 16px;
}
```

### Situation 7
Sehij ruft dich, weil sein Button nicht wie gewünscht horizontal zentriert ist. Finde konstruktive Hilfsfragen.

```css

  display: flex;
  align-items: center;
}
```

<details>
<summary>Der korrigierte Code</summary>

```css {3}
.container {
  display: flex;
  justify-content: center;
}
```
