# JavaScript-Grundlagen
Lernende bearbeiten Logik- und Syntaxaufgaben in JavaScript, um die Webseite für die Organisation einer Radtour interaktiv zu gestalten. Du begleitest den Lernprozess und unterstützt mit Micro-Scaffolding bei typischen Stolperfallen.

## Aufgabe: Hilfsfragen formulieren
Finde passende unterstützende Fragen nach den Regeln des Micro-Scaffolding für die folgenden Situationen beim Erlernen von JavaScript.
Gehe dabei wie folgt vor:

1. Analysiere den Fehler im Code. Falls nötig, betrachte die Lösung.
2. Formuliere eine **minimale** Hilfsfrage. Schreibe sie auf die <span style={{color: '#86aea6', fontWeight: 'bold'}}>grüne Karte</span>.
3. Formuliere eine **stärkere** Hilfsfrage. Schreibe sie auf die <span style={{color: '#e9c169', fontWeight: 'bold'}}>orangefarbene Karte</span>.

### Beispiel-Situation

```js
let fahrradfahrer = 10;
console.log(Fahrradfahrer);
```

:::tip[Scaffold]

<details style={{ backgroundColor: '#32965D40'}}>

<summary>Tipp 1</summary>

JavaScript unterscheidet strikt zwischen Groß- und Kleinschreibung (Case Sensitivity).

</details>

<details style={{ backgroundColor: '#FF9F1C40'}}>

<summary>Tipp 2</summary>

Vergleichen Sie die Bezeichner (Namen) in der Definition und in der Ausgabe ganz genau.

</details>

:::

### Situation 3: Temperatur-Check

```js
let temperatur = 0;

if (temperatur = 0) {
  console.log("Die Temperatur liegt genau am Gefrierpunkt");
}
```

<details>
<summary>Der korrigierte Code</summary>

```js {3}
let temperatur = 0;

}
```

### Situation 4: Alle verfügbaren Räder leihen

```js
let uebrigeFahrraeder = 8;

while (uebrigeFahrraeder > 0) {
  console.log("Es sind noch Räder im Verleih verfügbar");
}
```

<details>
<summary>Der korrigierte Code</summary>

```js {5}
let uebrigeFahrraeder = 8;

while (uebrigeFahrraeder > 0) {
  console.log("Es sind noch Räder im Verleih verfügbar");
  uebrigeFahrraeder = uebrigeFahrraeder - 1; // oder uebrigeFahrraeder--;
}
```

<div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginTop: '1rem' }}> <span>Schleifenvariable nicht verändert (-> Endlosschleife).</span> <a href="https://www.w3schools.com/js/js_loop_while.asp" target="_blank" style={{ backgroundColor: '#32965D', color: 'white', padding: '5px 12px', borderRadius: '6px', textDecoration: 'none', fontWeight: 'bold', fontSize: '0.85rem', whiteSpace: 'nowrap' }}> Mehr Hilfe im Web </a> </div>

### Situation 6: Budget-Rechner
Elif erhält "undefined" als Ergebnis ihrer Preisberechnung. Formuliere sinnvolle Hilfsfragen.

```js
function berechneGesamtpreis(radmiete, verpflegung) {
  radmiete + verpflegung;
}

console.log(berechneGesamtpreis(40, 20));
```

<details>
<summary>Der korrigierte Code</summary>

```js {2}
function berechneGesamtpreis(radmiete, verpflegung) {
  return radmiete + verpflegung;
}

console.log(berechneGesamtpreis(40, 20));
```

<div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginTop: '1rem' }}> <span>Rückgabe (```return```-Anweisung) fehlt.</span> <a href="https://www.w3schools.com/js/js_function_return.asp" target="_blank" style={{ backgroundColor: '#32965D', color: 'white', padding: '5px 12px', borderRadius: '6px', textDecoration: 'none', fontWeight: 'bold', fontSize: '0.85rem', whiteSpace: 'nowrap' }}> Mehr Hilfe im Web </a> </div>

### Situation 8: Letzter Teilnehmer
Lara möchte automatisch den letzten Namen der Liste ausgeben ("Tim"), erhält aber "undefined".

```js
let teilnehmer = ["Serhij", "Lara", "Tim"];

console.log(teilnehmer[teilnehmer.length]);
```

<details>
<summary>Der korrigierte Code</summary>

```js {3}
let teilnehmer = ["Serhij", "Lara", "Tim"];

console.log(teilnehmer[teilnehmer.length - 1]);
```

<div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginTop: '1rem' }}> <span>```length``` entspricht der Anzahl, der letzte Index ist immer ```length - 1```.</span> <a href="https://www.w3schools.com/jsref/jsref_length_array.asp" target="_blank" style={{ backgroundColor: '#32965D', color: 'white', padding: '5px 12px', borderRadius: '6px', textDecoration: 'none', fontWeight: 'bold', fontSize: '0.85rem', whiteSpace: 'nowrap' }}> Mehr Hilfe im Web </a> </div>
