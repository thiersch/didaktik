# JavaScript-Grundlagen
Lernende bearbeiten Logik- und Syntaxaufgaben in JavaScript, um die Webseite für den Skitag interaktiv zu gestalten. Du begleitest den Lernprozess und unterstützt mit Micro-Scaffolding bei typischen Stolperfallen.

## Aufgabe: Hilfsfragen formulieren
Finde passende unterstützende Fragen nach den Regeln des Micro-Scaffolding für die folgenden Situationen beim Erlernen von JavaScript.
Gehe dabei wie folgt vor:

1. Analysiere den Fehler im Code. Falls nötig, betrachte die Lösung.
2. Formuliere eine **minimale** Hilfsfrage. Schreibe sie auf die <span style={{color: '#86aea6', fontWeight: 'bold'}}>grüne Karte</span>.
3. Formuliere eine **stärkere** Hilfsfrage. Schreibe sie auf die <span style={{color: '#e9c169', fontWeight: 'bold'}}>orangefarbene Karte</span>.

### Beispiel-Situation

```js
let skifahrer = 10;
console.log(Skifahrer);
```

<details style={{ backgroundColor: '#32965D40'}}>

<summary>Tipp 1</summary>

</details>

<details style={{ backgroundColor: '#FF9F1C40'}}>

<summary>Tipp 2</summary>

JavaScript unterscheidet strikt zwischen Groß- und Kleinschreibung (Case Sensitivity).

</details>

:::

### Situation 4

```js
}
```

### Situation 6
Elif wundert sich, dass ihr Programm nichts ausgibt. Formuliere sinnvolle Hilfsfragen.

```js

  ticket + verleih;
}

console.log(berechneGesamtpreis(40, 20));
```

<details>
<summary>Der korrigierte Code</summary>

