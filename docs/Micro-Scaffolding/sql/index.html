SQL-Grundlagen

Lernende nutzen SQL, um die organisatorischen Daten einer Radtour zu verwalten. Du begleitest den Lernprozess und unterstützt mit Micro-Scaffolding bei Abfragen und Datenbank-Strukturen.

Aufgabe: Hilfsfragen formulieren​

Finde passende unterstützende Fragen nach den Regeln des Micro-Scaffolding für die folgenden Situationen beim Erlernen von SQL. Gehe dabei wie folgt vor:

  1. Analysiere den Fehler im Code. Falls nötig, betrachte die Lösung.
  2. Formuliere eine minimale Hilfsfrage. Schreibe sie auf die grüne Karte.
  3. Formuliere eine stärkere Hilfsfrage. Schreibe sie auf die orangefarbene Karte.

Beispiel-Situation​

SELECT nachname FROM teilnehmer
WERE vorname = 'Lara';

Tipp 1

Tipp 2

Lösung
Der korrigierte Code
SELECT nachname FROM teilnehmer
WHERE vorname = 'Lara';
Fehlender Buchstabe in WHERE. Mehr Hilfe im Web

Situation 1: Alle Tour-Teilnehmer anzeigen​

SELECT ALL FROM teilnehmer;
Der korrigierte Code
SELECT * FROM teilnehmer;
Falscher Platzhalter für "alle Spalten". Mehr Hilfe im Web

Situation 2: Nach Zielort filtern​

SELECT * FROM touren
WHERE zielort = Bodensee;
Der korrigierte Code
SELECT * FROM touren
WHERE zielort = 'Bodensee';
Fehlende Anführungszeichen bei String. Mehr Hilfe im Web

Situation 3: Neue Tour hinzufügen​

INSERT INTO touren (ziel, distanz)
VALUES (120, 'Alpen');
Der korrigierte Code
INSERT INTO touren (ziel, distanz)
VALUES ('Alpen', 120);
Reihenfolge der Werte passt nicht zu den Spalten. Mehr Hilfe im Web

Situation 4: Teilnehmerliste sortieren​

SELECT nachname FROM teilnehmer
SORT BY nachname;
Der korrigierte Code
SELECT nachname FROM teilnehmer
ORDER BY nachname;
Falsches Schlüsselwort für Sortierung. Mehr Hilfe im Web

Situation 5: Radmiete aktualisieren​

UPDATE leihraeder
SET status = 'verliehen'
WHERE rad_id == 105;
Der korrigierte Code
UPDATE leihraeder
SET status = 'verliehen'
WHERE rad_id = 105;
Vergleichsoperator verwechselt. Mehr Hilfe im Web

Situation 6: Anzahl der Anmeldungen zählen​

SELECT COUNT FROM anmeldungen;
Der korrigierte Code
SELECT COUNT(*) FROM anmeldungen;
Funktionsklammern bei COUNT fehlen. Mehr Hilfe im Web

Situation 7: Touren filtern​

Tim möchte Touren für Heidenheim und Ulm zeigen. Er wundert sich, warum die Ergebnisliste leer bleibt.

SELECT * FROM touren
WHERE startort = 'Heidenheim' AND startort = 'Ulm';
Der korrigierte Code
SELECT * FROM touren
WHERE startort = 'Heidenheim' OR startort = 'Ulm';
Schnittmenge statt Vereinigung. Mehr Hilfe im Web

Situation 8: Abmeldung verarbeiten​

Ein Teilnehmer hat seine Teilnahme an der Radtour storniert. Jana möchte den Datensatz entfernen, löscht aber versehentlich die gesamte Tabelle.

DELETE FROM teilnehmer;
Der korrigierte Code
DELETE FROM teilnehmer 
WHERE teilnehmer_id = 42;
Fehlende WHERE-Klausel. Mehr Hilfe im Web
